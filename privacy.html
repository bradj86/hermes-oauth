Privacy Policy

Application: Hermes Agent
Effective date: 17 October 2026
Contact: bradjamesevans1986@gmail.com

1. Summary

Hermes Agent is a private, single-user automation integration. It accesses Google user data belonging solely to its owner, uses that data solely to perform tasks for that owner, and shares it with nobody.

2. What data is accessed

With the owner's explicit authorisation, and limited to the owner's own Google Account:

  • Gmail — message metadata and content, so mail can be sorted, flagged and replied to on the owner's behalf.
  • Google Calendar — so reminders and due dates can be created and updated.
  • Google Drive — so documents the owner generates can be uploaded and shared back to the owner.
  • Google Sheets and Docs — so structured records kept by the owner can be read and updated.
  • Contacts (read-only) — so senders can be identified.

3. How data is used

Accessed data is used only to carry out the automation tasks the owner has asked for: triaging and drafting email, creating calendar entries, and filing documents. Data is processed on the owner's own computer. It is not used to build profiles, not used for advertising, and not used to train or improve any machine-learning model.

4. Storage and retention

  • OAuth credentials are stored locally on the owner's own machine, protected by the operating system's file permissions.
  • A local cache of recent email metadata may be kept briefly so that repeated runs do not re-read the same messages. It is not backed up to any third party.
  • Data may be deleted at any time by the owner, and the authorisation can be revoked at any time at myaccount.google.com/permissions.

5. Sharing and disclosure

Google user data is not sold, rented, traded or transferred to any third party. It is not disclosed to advertisers, data brokers, information resellers, or any other party. No human other than the owner reads it. Where a task requires calling a third-party API, only the minimum content required for that single operation is sent, and only at the owner's direction.

6. Limited Use

Hermes Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. In particular:

  • Google user data is used only to provide or improve user-facing features that are prominent in the application's interface.
  • Google user data is not transferred to others except as necessary to provide or improve those features, to comply with applicable law, or as part of a merger or acquisition with notice to users.
  • Google user data is not used or transferred for serving advertisements.
  • No human reads the data except the owner, for security purposes, to comply with law, or with the owner's explicit consent.

7. Security

Access is via Google's OAuth 2.0 framework. Tokens are scoped to the minimum required and are stored only on the owner's machine. The application runs on a single personal computer that is not a shared service.

8. Children

The application is private and single-user. It is not directed at children and has no public users.

9. Changes

Any change to this policy will be published on this page with a revised effective date.
