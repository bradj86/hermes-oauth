Hermes Agent

A private, single-user automation integration for Google Workspace.

What this is

Hermes Agent is a personal automation tool operated by, and for, a single individual user — its owner. It connects to that owner's own Google Account so that routine tasks can be handled automatically: reading and organising the owner's own email, drafting replies for the owner to review, placing bill and renewal dates on the owner's own calendar, and uploading documents the owner has generated into the owner's own Google Drive.

Who uses it

One person: the owner of the Google Account that authorises it. Hermes Agent is not offered, distributed or licensed to the public, it has no third-party users, and it has no sign-up. It is not a commercial product and it is not available to anyone other than its owner.

How it uses Google data

  • It accesses only the owner's own Google Account data.
  • It requests the narrowest scopes that let it perform the tasks above.
  • It does not sell, rent, trade or transfer Google user data to anyone.
  • It does not use Google user data for advertising, profiling or training machine-learning models.
  • No human other than the owner reads the owner's data.

Its use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
